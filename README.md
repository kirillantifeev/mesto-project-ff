# Проектная работа "Mesto"

Это интерактивная страница, куда можно добавлять фотографии с подписями, удалять их, ставить лайки. Также можно редактировать данные пользователя, менять его аватарку.

https://kirillantifeev.github.io/mesto-project-ff/

[Макет](<https://www.figma.com/file/vIywAvqfkOIRWGOkfOnReY/React-Fullstack_-Проектные-задачи-(3-месяца)_external_link?type=design&node-id=0-1&mode=design](https://www.figma.com/design/bjyvbKKJN2naO0ucURl2Z0/JavaScript.-Sprint-5?node-id=0-1&p=f&t=Z44R4keaDrvgneyK-0)>)

## Запуск проекта

Сборка проекта: 
```
npm run build
```

Запуск на локальном сервере:
```
npm run dev
```

## Что было выполнено: 

0. Сборка с помощью Webpack.
1. Работа модальных окон: открытие и закрытие модального окна
2. Закрытие модальных окон по кнопке, по оверлею, с помощью ESC
3. Редактирование данных пользователя с помощью формы
4. Реализация добавления новой карточки
5. Реализация лайка
6. Реализация открытия попапа с картинкой.
7. Плавность открытия и закрытия модальных окон.
8. Реализация валидации форм.
9. Интеграция с Api, загрузка с сервера таких данных, как: данные пользователя, карточки, колличество лайков.
10. Отправка данных на сервер (данные пользователя, создание новой карточки, удаление карточки пользорвателя, постановка и снятие лайка).
